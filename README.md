# Bank Review Analysis

## Task 1 — Data Collection & Preprocessing

### Steps:
1. Scrape Google Play reviews for:
   - Commercial Bank of Ethiopia (CBE)
   - Bank of Abyssinia (BOA)
   - Dashen Bank

2. Save raw reviews → data/raw_reviews.csv

3. Preprocess:
   - Remove duplicates
   - Clean dates
   - Normalize text
   - Save final dataset → data/clean_reviews.csv

4. Minimum:
   - 400+ reviews per bank
   - 1200+ total
